# Refinement log for the learning track

One entry per pass, in the formats set by `lab/refine/TEMPLATES.md`: pass entries, owner
corrections and the closing state-of-the-run section. The rubric the passes judge this track
against is `lab/refine/learning/RUBRIC.md`. The counter in `refine_pass.txt` is incremented only as
the last step of a completed pass. Owner corrections made outside a pass are recorded here too, so
a pass never undoes one, but they do not increment the counter.
