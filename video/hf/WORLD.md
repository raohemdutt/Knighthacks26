# The Atlas world (HyperFrames build of the Devpost video)

One continuous 3D world, one camera. The film is about three minutes, ten scenes back to back, no title cards, no app
recordings: every scene is a camera journey that starts where the previous one left the camera and hands over. The
world holds the **Atlas enclosure** (dimensionally true, every part movable), the **dorm room** set around its desk,
the **kitchen** set far to the left, and the older axes (time ring, lab, friends, campus, membrane).

| Axis / set | What it shows | Objects |
| --- | --- | --- |
| Depth | the enclosure and its parts: webcam, lid, Jetson, speaker, honeycomb front, cardboard walls | `atlas`, `parts`, `state.explode`, `state.xray`, `state.hl.*` |
| Room | the desk the box sits on, the person at the monitor | `room`, `state.room`, `state.person`, `state.personLook` |
| Kitchen | the bins, the bin camera, a second Atlas, the can | `kitchen`, `state.kitchen`, `state.canThrow`, `state.binCount` |
| Time | the day as a ring on the desk; frames become beads, beads become bars | `ring`, `beads`, `state.ring`, `state.beads`, `state.bars` |
| Space | desk, then lab (two AMD Strix Halo pods, "Trainer A" / "Trainer B"), friends' boxes, campus | `lab`, `friends`, `campus` |
| Membrane | the privacy shell around the box; only counted particles cross it | `membrane`, `state.membrane`, `world.flow(...)` |

## Layout of the project

```
video/hf/
  film.yaml               THE SCRIPT: scenes, words. python video/scripts/film_build.py speaks it and lays it out
  film.json               GENERATED: fps, total_s, scenes[{id,title,start,duration,lines[{text,start,duration}]}], absolute seconds
  index.html              GENERATED by film_build.py, never edit by hand
  world/world.js          the shared Three.js world (renderer, light, camera rig, state, axes, particles, labels)
  world/sets/common.js    palette, hash, mm()/mmBox()/boxMesh() (CAD mm -> world), materials, fadingSet
  world/sets/enclosure.js the Atlas enclosure (hero) and the shell-only copy (friends, kitchen)
  world/sets/person.js    the stylised person rig (seated / standing poses, look())
  world/sets/room.js      the dorm room set
  world/sets/kitchen.js   the kitchen set (KX = -42)
  world/ENCLOSURE.md      the real dimensions the enclosure is built from
  world/soft.css          the soft-UI tokens and classes for every 2D overlay
  world/scenes/<id>.js    default export: (tl, world, scene) => void, the camera + world choreography of that scene
  compositions/<id>.html  the 2D soft-UI overlay of that scene (a HyperFrames sub-composition, local time 0..scene.duration)
  assets/voice/*.mp3      the narration, one file per spoken line (copied by film_build.py)
  review/                 the world agent's review frames (a-assembled ... f-bincam)
  reference/              choreography written for the earlier ten-slot cut; mine it, do not import it
```

Time: 30 fps. Scene starts and durations come from film.json (they move when words change, so never hard-code
them: read `scene.start`, `scene.duration`, `scene.lines[i].start`). The narration starts at `scene.start`
(`+ lead_s` for the intro). Choreograph to the words.

Scale: **1 unit = 100 mm**. The desk top (studio and room) is at y = -1.0; the room and kitchen floor at y = -8.5
(a 75 cm desk). The box is small: 1.25 wide x 0.80 tall (1.24 with the webcam) x 1.98 deep, centred on x/z, front
facing +z. Facing the front, the device's right (the lid's cable gap) is screen-left.

## The world API (world.js) — frozen

```js
import { createWorld } from "./world/world.js";
const world = await createWorld(canvas);     // builds the scene; resolve buildReady after this
world.render(t);                             // draws the frame for absolute time t (seconds). Pure function of state + t.
```

Everything a scene animates is a NUMBER on one of these objects. Tween them with GSAP on the ROOT timeline at
absolute time (`t0 + local seconds`). Never read the clock, never randomise.

### Camera

- `world.cam` — `{ x, y, z, tx, ty, tz, fov }` camera position, look-at target, field of view.
  `world.leg(tl, at, to, dur, ease)` is sugar for `tl.to(world.cam, { ...to, duration: dur, ease }, at)`.
- `world.HOME` = `SHOTS.home` = `{ x: 3.0, y: 1.1, z: 4.6, tx: 0, ty: -0.42, tz: 0.05, fov: 30 }`: a studio
  three-quarter of the enclosure from the front-right, no room.
- `world.SHOTS` — named shots (plain camera objects; pass to `world.leg`):

| Shot | What is in frame |
| --- | --- |
| `home` | the assembled enclosure, studio three-quarter (= HOME) |
| `front` | straight on the honeycomb front and the logo |
| `hero` | low left three-quarter (the cable side) |
| `xray` | high three-quarter into the box (use with `xray` 1) |
| `exploded` | the whole exploded diagram (use with `explode` 1) |
| `deskClose` | tight on the device on the desk (room or studio) |
| `roomWide` | the room from the right: the person in profile at the monitor, the device on the desk, window and shelf |
| `overShoulder` | behind the person toward the monitor and the device |
| `kitchenWide` | the kitchen: three bins, the wall camera, the counter with the second Atlas, the fridge, the person |
| `binCam` | from the wall camera, looking down at the bins and the person (wide angle, like a security cam) |
| `counterAtlas` | tight on the counter device |

The kitchen is 42 units to the left: a `leg` from the room to `kitchenWide` is a long travel (1.5 s minimum).

### State (`world.state`)

The enclosure:
- `explode` 0..1 — every part slides out along its own direction: lid up, clip and webcam higher, walls outward,
  back wall back, front panel and floor rail forward, speaker forward-down, Jetson up-back (its heat sink and fan
  lift a little more); the whole diagram floats up 0.3. A clean exploded diagram at 1. The cable fades out.
- `xray` 0..1 — walls, back, lid (and most of the front) go glassy with thin outlines; the parts read inside.
- `hl` — `{ webcam, jetson, speaker, lid, front }`, each 0..1: the part tints 35 % toward the accent with a small
  emissive and a thin accent rim (front: an accent frame). Tween the object itself: `tl.to(world.state.hl, { jetson: 1 }, at)`.
  `hl.webcam` includes the clip; `hl.front` includes the floor rail.
- `pulse` 0..1 — a slow heartbeat (2 s period) on the Jetson: its LED goes accent, the board warms, and a warm glow
  breathes through the lid's vent slots (visible from outside).
- `eyes` 0..1 — the webcam lens warms up in the accent with a thin halo; the camera's LED turns accent.
- `cable` 0..1 — the Ethernet cable from the back wall's jack (`P.ethernet`) droops to the desk; 1 = pulled out and dropped.
- `drop` 0..1 — the parts are in the air (1) and fall into place in assembly order as it goes to 0 (bottom, back,
  walls, speaker, Jetson, front, lid, clip, webcam). A small negative value squashes for a settle. Cable hidden while airborne.
- `spin` — the enclosure's rotation in turns (anchors ignore spin).
- Legacy aliases (kept so old scene files load; do not use in new work): `open` = explode (max of the two),
  `layer[0]` = hl.webcam, `layer[1..3]` = hl.jetson. `world.SLAB` and `world.layerY(i)` still exist and point at the new parts.

The sets:
- `room` 0..1 — the dorm room rises and fades in around the desk (desk, monitor with a clip-on webcam, keyboard,
  mouse, mug, notebook, lamp, chair, rug, back wall with a window over the bed on the left, a shelf with books on the
  right). The studio shadow plane gives way to the room's own surfaces.
- `person` 0..1 — the seated person (shows only while `room` > 0). `personLook` 0..1 turns their head (and a little
  of the torso) from the monitor to the device.
- `kitchen` 0..1 — the kitchen rises in at x = -42 (the person standing by the bins with a can comes with it; the
  shadow frustum slides there as it rises).
- `canThrow` 0..1 — 0..0.18 the arm swings, then the can flies in an arc from the hand into the grey trash bin (lands at 1).
- `binCount` 0..1 — the counter Atlas lights up (accent tint, vent glow, lens).

The axes (unchanged meaning, rescaled to the real box):
- `membrane` 0..1 — the privacy shell: an ellipsoid (radii 1.3 x 1.0 x 1.75) around the box, centred at y = -0.4.
- `ring` 0..1 — the time ring on the desk, radius 3. `beads` 0..48 beads on it; `bars` 0..1 grows them into bars.
- `lab` 0..1 — the lab at x = +14 (two Strix Halo pods, plates "Trainer A" / "Trainer B"). `labGlow`, `labCurve` as before.
- `friends` 0..1 — three shell-only copies of the enclosure at radius 5.5, each in its own shell, facing the centre.
  `friendsLink` 0..1 draws links (and warms the copies a little).
- `campus` 0..1 — the campus map plane; `route` 0..1 draws the Day Run route.
- `blur` — reserved (unused by the world).

### Anchors (`world.P`, world coordinates, assembled)

| Anchor | Where |
| --- | --- |
| `P.box` | the enclosure's centre `[0, -0.45, 0]` |
| `P.webcam` | the webcam lens |
| `P.jetson` | the Jetson's centre |
| `P.speaker` | the speaker's fabric front |
| `P.lid` | the lid's top face, centre |
| `P.front` | the honeycomb front's face |
| `P.ethernet` | the Ethernet jack on the back wall |
| `P.lab`, `P.friend[i]`, `P.ring(a)` | as before (lab `[14, 0.8, -2]`; friends at radius 5.5; ring radius 3) |
| `P.desk`, `P.monitor`, `P.keyboard`, `P.person` | the room (person = the head) |
| `P.kitchen`, `P.bins[0..2]`, `P.binCam`, `P.counterAtlas` | the kitchen (bins: blue recycle, green compost, grey trash, at the rim) |

`world.at(name, e)` returns an anchor or part position at explode `e` (default 0), e.g. `world.at("jetson", 1)` for a
label on the exploded diagram. Names: the anchors above plus `clip`, `rail`, `wallL`, `wallR`, `back`, `bottom`.

### Flows and labels

- `world.flow(id, { from, to, count, color, size, lift })` — declares a particle stream once. Returns `world.flows[id]` =
  `{ progress, density, spread }`: tween `progress` 0..1 to send the particles along an arc; `density` 0..1 fades them.
- `world.label(id, { text, at, size, scale })` — a soft-UI card at a 3D point, always facing the camera, drawn on top.
  Returns `world.labels[id]` = `{ opacity, lift }`. Size: `scale` 1 = 4 x 1 units, so use about 0.24 near the box
  and 1 for the room. Keep labels to 1–3 words.

### Other handles

`world.parts` (each `{ g, rest, offset, mats, ... }`, the part Groups), `world.atlas`, `world.room`, `world.kitchen`
(`.person`, `.bins`), `world.pods`, `world.friends`, `world.membrane`, `world.KX`, `world.hash`.

### Look

Image-based light (RoomEnvironment through PMREM, `envMapIntensity` 0.35 on the matte materials, scene factor 0.6),
ACES filmic tone mapping at exposure 1.0, VSM soft shadows. The key light's shadow frustum follows the action: tight
(±3.2) around the box in the studio, widening to ±26 with `room`, `kitchen`, `lab`, `friends`, `campus`, `ring`, and
sliding to the kitchen as `kitchen` rises. Accent lines, rims, labels and map textures are not tone mapped, so the
accent stays #d9774a. Cardboard is a warm matte kraft-grey; printed parts are the soft white surface.

## Rules for choreography files (`world/scenes/<id>.js`)

- `export default function choreograph(tl, world, scene) { ... }`; `const t0 = scene.start`; every position
  parameter is `t0 + seconds` or `scene.lines[i].start + seconds`; nothing may run past `t0 + scene.duration`.
  Only index `scene.lines[i]` that exist (a missing line throws and kills the whole timeline).
- The camera is continuous across scenes: start from the shot the previous scene hands over (see the hand-over
  table below) and leave the camera at your own hand-over shot. No `tl.set` on the camera except inside a planned
  hard cut (announce it in the table).
- Ease law: `power4.out` on dives and landings, `power2.inOut` on repositioning, `none` on steady drifts. No
  spring or back easing on the camera.
- One tween per property per moment. Scenes do not overlap; reset what you changed before your scene ends unless
  the hand-over table says the next scene inherits it.
- Motivate every move with a spoken line: land the camera when the word lands.

Rules for overlays (`compositions/<id>.html`): a sub-composition (everything inside `<template>`, root
`<div id="root" data-composition-id="<id>" data-width="1920" data-height="1080">`, timeline registered at
`window.__timelines["<id>"]`, local time). Prefix every id with `<id>-`. Use `world/soft.css` classes. Captions and
narration are at the root; do not add them. The world canvas is under the overlay and transparent areas show it.
