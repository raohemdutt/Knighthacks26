# The Atlas world (HyperFrames build of the Devpost video)

One continuous 3D world, one camera, the box never leaves frame. The film is about three minutes, ten scenes back
to back, no title cards, no app recordings: every scene is a camera journey that starts where the previous one left
the camera, travels along one axis, and hands over. The four axes:

| Axis | What it shows | Objects in `world.js` |
| --- | --- | --- |
| Depth | the four layers inside the box: cameras, vision, memory, agent | `box`, `layers[0..3]`, `state.open`, `state.layer[i]` |
| Time | the day as a ring on the desk; frames become beads, beads become bars | `ring`, `beads`, `state.ring`, `state.beads` |
| Space | desk, then lab (two AMD Strix Halo pods), then friends' boxes, then the campus | `lab`, `friends`, `campus`, `state.lab`, `state.friends`, `state.campus` |
| Membrane | the privacy shell; only counted particles cross it | `membrane`, `state.membrane`, `world.flow(...)` |

## Layout of the project

```
video/hf/
  film.yaml               THE SCRIPT: scenes, words. python video/scripts/film_build.py speaks it and lays it out
  film.json               GENERATED: fps, total_s, scenes[{id,title,start,duration,lines[{text,start,duration}]}], absolute seconds
  index.html              GENERATED by film_build.py, never edit by hand
  world/world.js          the shared Three.js world (scene, camera rig, state, particles, labels)
  world/soft.css          the soft-UI tokens and classes for every 2D overlay
  world/scenes/<id>.js    default export: (tl, world, scene) => void, the camera + world choreography of that scene
  compositions/<id>.html  the 2D soft-UI overlay of that scene (a HyperFrames sub-composition, local time 0..scene.duration)
  assets/voice/*.mp3      the narration, one file per spoken line (copied by film_build.py)
  reference/              choreography written for the earlier ten-slot cut; mine it, do not import it
```

Time: 30 fps. Scene starts and durations come from film.json (they move when words change, so never hard-code
them: read `scene.start`, `scene.duration`, `scene.lines[i].start`). The narration starts at `scene.start`
(`+ lead_s` for the intro). Choreograph to the words.

## The world API (world.js)

```js
import { createWorld } from "./world/world.js";
const world = await createWorld(canvas);     // builds the scene; resolve buildReady after this
world.render(t);                             // draws the frame for absolute time t (seconds). Pure function of state + t.
```

Everything a slot animates is a NUMBER on one of these objects. Tween them with GSAP on the ROOT timeline
at absolute time (`t0 + local seconds`). Never read the clock, never randomise.

- `world.cam` — `{ x, y, z, tx, ty, tz, fov }` camera position, look-at target, field of view.
  `world.leg(tl, at, to, dur, ease)` is sugar for `tl.to(world.cam, { ...to, duration: dur, ease }, at)`.
  Home shot: `world.HOME` = `{ x: 0, y: 2.2, z: 8.5, tx: 0, ty: 0.2, tz: 0, fov: 35 }`.
- `world.state` —
  - `open` 0..1: the four layers spread apart vertically. `spin`: box rotation in turns (0.25 = quarter turn).
  - `layer[0..3]` 0..1: that layer lit in the accent colour (cameras, vision, memory, agent, bottom to top).
  - `membrane` 0..1: the privacy shell's visibility around the box (sphere, radius 2.6).
  - `ring` 0..1: the time ring on the desk (radius 4). `beads` 0..48: how many beads sit on the ring. `bars` 0..1: beads grow into bars.
  - `lab` 0..1: the lab at x = +14 (two AMD Strix Halo pods, Radeon 8060S each) fades/scales in. `labGlow` 0..1: the slabs glow warm (watts). `labCurve` 0..1: the loss ribbon draws.
  - `friends` 0..1: three friend boxes around the desk at radius 9. `friendsLink` 0..1: links between the shells draw.
  - `campus` 0..1: the campus map plane under everything. `route` 0..1: the Day Run route draws on it.
  - `cable` 0..1: the network cable pulls out of the box (1 = unplugged). `pulse` 0..1: the box's heartbeat glow.
  - `blur` 0..1: outer-focus falloff (cheap depth of field on the overlay; the world keeps crisp).
- `world.flow(id, { from, to, count, color, size })` — declares a particle stream once (call at build time, from
  the slot's choreography). Returns `world.flows[id]` = `{ progress, density, spread }`: tween `progress` 0..1
  to send the particles along an arc from `from` to `to`; `density` 0..1 fades them. Points are `[x, y, z]`;
  `world.P.box`, `world.P.lab`, `world.P.friend[i]`, `world.P.ring(angle)` give the useful anchors.
- `world.label(id, { text, at, size })` — a soft-UI label that lives at a 3D point and always faces the camera.
  Returns `world.labels[id]` = `{ opacity, lift }`. Keep labels to 1–3 words; the overlay does sentences.

Rules for choreography files (`world/scenes/<id>.js`):
- `export default function choreograph(tl, world, scene) { ... }`; `const t0 = scene.start`; every position
  parameter is `t0 + seconds` or `scene.lines[i].start + seconds`; nothing may run past `t0 + scene.duration`.
- The camera is continuous across scenes: start from the shot the previous scene hands over (see the hand-over
  table below) and leave the camera at your own hand-over shot. No `tl.set` on the camera except inside a planned
  hard cut (announce it in the table).
- Ease law: `power4.out` on dives and landings, `power2.inOut` on repositioning, `none` on steady drifts. No
  spring or back easing on the camera.
- One tween per property per moment. Scenes do not overlap; reset what you changed before your scene ends unless
  the hand-over table says the next scene inherits it.
- Motivate every move with a spoken line: look up the line's `start` in voice.json and land the camera when the
  word lands.

Rules for overlays (`compositions/slot-N.html`): a sub-composition (everything inside `<template>`, root
`<div id="root" data-composition-id="slot-N" data-width="1920" data-height="1080">`, timeline registered at
`window.__timelines["slot-N"]`, local time). Prefix every id with `slot-N-`. Use `world/soft.css` classes.
The title card (first 1.5 s): the key cap `N` pressed down, the slot title, the watcher line. Captions and
narration are at the root; do not add them. The world canvas is under the overlay and transparent areas show it.
