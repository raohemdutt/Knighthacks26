# Waste Watch

**The local problem, stated plainly:** at a shared table, most of what gets thrown away is cans, bottles and cups, and a good part of it lands in the wrong bin, because the rules differ from place to place and nobody is told when they get one wrong; one food-soiled bowl in the recycling can send the good items around it to landfill too. **What is measured:** a camera at the table counts each single-use item once (`impact.item.seen`) and records which bin zone it ends in and whether that was right (`impact.item.disposed`), which gives items seen, recyclables seen, recyclables recycled, wrong items in recycling (contamination), the diversion rate (recycled divided by recyclables seen), and the same numbers before and after the box started nudging about sorting, with n on each side and "not enough data yet" below five a side; these are counts from our own table, not estimates. The Impact screen (`/impact/`, `GET /api/impact/story`) then turns the week's count into grams, kilowatt-hours, phone charges and CO2e, always as a range and always labelled as an estimate, using the factors in `config/impact.yaml`, each of which carries a `source` and a `confidence`; those factors are illustrative and are meant to be replaced. It also shows every disposal with the rule for a wrong one, a weekly goal, clean days in a row, milestones (`impact.milestone.reached`), and the week's mistakes as a practice set for Sort It (`GET /api/impact/practice`). **What another campus changes to reuse it:** one file. `config/sorting.yaml` holds the bins, which bin each item belongs in, and one sentence per item saying why; replace it (or add `config/profiles/<name>/sorting.yaml` and start the box with `ATLAS_PROFILE=<name>`), and the same cameras, the same event stream and the same code give that place's verdicts and that place's explanations. `config/profiles/family-home/sorting.yaml` is a complete second file that sorts four items differently from the UCF one (paper cups, rinsed takeout containers, milk cartons and juice boxes go in recycling there), and `contexts/impact/tests/test_story.py` runs one event stream through both to show the verdicts and sentences differ. A campus that wants its own real-unit figures also edits `config/impact.yaml`; nothing else changes.
